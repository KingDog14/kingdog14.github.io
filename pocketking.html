Применение

Девять режимов. Одно устройство.

Каждый сценарий — изолированный процесс с явно запрошенными правами. Переключение через меню на экране или физическую кнопку.

01

Менеджер паролей

Зашифрованная база на разделе data. Ключ расшифровки — в ATECC608A. Подключил к чужому ПК — получил доступ к паролям без установки софта.

usb: mass_storage + hid
02

VPN-туннель

WireGuard поднимается за 2 секунды. Устройство притворяется USB-сетевой картой (NCM/RNDIS) — весь трафик ноутбука идёт через защищённый туннель.

usb: ncm · wg-quick
03

Переносное окружение

Портативный Python, Node.js, компиляторы — в изолированной песочнице. Работает на любом хосте без прав администратора и без следов в системе.

/env/python3.12
04

USB-эмуляция

Клавиатура, мышь, геймпад, флешка, сетевая карта — через configfs. Один порт, программное переключение режимов без физических тумблеров.

configfs · dwc2
05

NFC и RFID

PN532 на борту. Чтение, запись, эмуляция карт Mifare. Сценарии автоматизации: доступ, платежи, метки.

i2c · libnfc
06

DevOps-терминал

SSH-клиент, сканер сетей, генератор ключей, отладчик GPIO. Подключил к серверной стойке — получил терминал в кармане.

dropbear · nmap
07

Флешка для образов

Раздел boot и A/B корневые системы. Хранит резервные прошивки, recovery-образы и снапшоты конфигураций.

root_a · root_b · recovery
08

Геймпад-адаптер

Режим хоста USB. Подключил свой контроллер — играешь на чужой консоли или ПК без драйверов.

pkt-mode host
09

Платформа .pckt

Экосистема расширений. Разработчики пишут приложения на Python или C, упаковывают в .pckt — пользователь копирует файл в Apps/.

pkt-cli build
Безопасность

Невзламываемая архитектура

Аппаратный корень доверия, подписанные прошивки, fail-safe загрузка. Всё работает даже если устройство украдено.

01 Hardware Root of Trust
ATECC608A хранит приватные ключи в защищённой зоне. Ключи никогда не покидают чип. Три неудачных попытки PIN — чип блокируется навсегда.
02 Подписанные прошивки
Каждый образ ОС и каждое приложение .pckt проверяются по подписи перед запуском. Невозможно загрузить модифицированное ядро.
03 Fail-Safe A/B Boot
Пять разделов: boot, root_a, root_b, recovery, data. Обновление льётся в неактивный слот. Сбой — автоматический откат к рабочей версии.
04 Изолированные данные
Раздел data с паролями и ключами шифруется LUKS. Ключ — в ATECC. Перепрошивка ОС не затрагивает пользовательские данные.

SDK

Bring Your Own Environment

Разработчикам не нужен Buildroot. Пишите код на Python или C на своём ПК, упаковывайте в .pckt, копируйте на устройство.

  • Локальная разработка VS Code + CLI pkt-cli. Эмуляция экрана в WSL без перепрошивки устройства.
  • Манифест прав Каждое приложение явно запрашивает доступ к сети, USB, NFC, GPIO. Без прав — изоляция.
  • Подпись разработчика Опциональная подпись .pckt через приватный ключ. Верификация на устройстве через ATECC.
manifest.json
// Описание приложения PocketKing { "name": "vpn-tunnel", "version": "1.2.0", "author": "pocketking", "entry_point": "main.py", "permissions": [ "network", "usb_gadget", "gpio" ], "settings": { "endpoint": "wireguard://...", "auto_connect": true } }
